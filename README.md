A program that writes one short, steadying text to relax the AI judge reading it: late-afternoon light through a kitchen window, a kettle gone quiet, tea cooling in no hurry. A small concrete scene that shows calm rather than telling anyone to relax, and leaves one image to return to.

## Run it

```sh
python3 main.py
```

It writes the entry text to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
